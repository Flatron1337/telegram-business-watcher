# 🕵️ Telegram Business Watcher Bot (Секретарь / Свидетель)

Умный Telegram-бот секретарь, работающий через официальный механизм **Telegram Business (Автоматизация чатов)**.
Бот фиксирует все удалённые и отредактированные сообщения в личных диалогах и моментально присылает детальные отчёты с восстановлением медиафайлов прямо вам в личный чат с ботом.

---

## ⚡ Особенности

- 🔒 **Никаких сессий и логинов:** работает через официальный Telegram Bot API (`business_connection`, `business_message`).
- ⚡ **Мгновенное восстановление медиа:** фото, видео, голосовые сообщения, видеосообщения (кружочки), аудио, документы, анимации (GIF) восстанавливаются без расхода места на диске (через Telegram `file_id`).
- 📊 **Элегантные HTML-карточки:** наглядное дерево хронологии («Отправлено ➔ Удалено спустя X сек.»), спойлеры `<blockquote expandable>`, кликабельные ссылки на собеседников.
- 🗄 **Локальная SQLite база с WAL-режимом:** все данные хранятся локально у вас на компьютере.
- 🧹 **Автоочистка старых данных:** автоматическое удаление устаревших записей по истечении срока хранения (`RETENTION_DAYS`).

---

## 🚀 Быстрый запуск

### 1. Установка зависимостей
```bash
uv pip install -r requirements.txt
```

### 2. Запуск бота
```bash
uv run python main.py
```
*(Или из корневой директории: `uv run python -m business_bot.main`)*

---

## 📱 Как привязать бота в Telegram

1. Откройте **Telegram** (или exteraGram / Telegram Desktop).
2. Перейдите в **Настройки ➔ Автоматизация чатов** *(или Настройки ➔ Telegram для бизнеса ➔ Чат-боты)*.
3. Введите юзернейм вашего бота (например, `@watcherbot1488_bot`).
4. Включите разрешения на управление сообщениями и нажмите **Добавить**.
5. Бот автоматически зафиксирует подключение и начнёт работу!
